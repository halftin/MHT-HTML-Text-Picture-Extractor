## 📖 项目简介

MHT资源提取器是一款专注于解析和提取`.mht`（MIME HTML）文件内容的工具。它能够将网页归档文件中的纯文本与嵌入式图片等资源高效分离，并以结构化的方式输出。本工具采用本地运行模式，无需联网即可操作，确保了用户数据的安全性与隐私性。项目采用 Java 21 + JavaFX 21 构建，使用 MVC 架构设计，代码模块化、可维护性强。

## ⚙️ 主要功能

### 📝 纯文本提取

- **智能编码修复**：通过多种编码组合交叉尝试（UTF-8、GBK、ISO-8859-1等），基于文本质量评分自动选择最佳结果，有效修复乱码。
- **内容区域限定**：通过设置起始与结束标记（支持正则模式），仅提取HTML中指定区间的文本内容。
- **灵活输出模板**：支持自定义开头/结尾模板，可动态插入文件名、时间戳等变量（`{filename}`、`{datetime}`、`{date}`、`{time}`）。
- **章节序号生成**：自动为合并输出的文件添加中文章节序号（第一章、第二章……第一百二十三章），支持1-9999章。
- **隐藏标题提取**：通过标记定位HTML中的隐藏标题内容，可结合章节序号一同输出。
- **合并/单独输出**：支持将所有文件合并为单一TXT，或为每个MHT文件生成独立的TXT。

### 🖼️ 图片提取

- **广告过滤机制**：基于关键词列表自动识别并过滤广告类图片（banner、promo、ads等）。
- **智能重命名**：支持按数字序列（001.jpg, 002.png...）对提取的图片进行批量重命名。
- **ZIP/CBZ 打包**：可选将提取的图片打包为ZIP压缩文件或CBZ漫画归档文件，打包后自动清理临时目录。
- **图片名称提取**：通过HTML标记提取原始图片文件名。
- **图片区域限定**：仅提取HTML中指定区域内的图片资源。
- **魔数检测**：基于文件头魔数自动识别图片真实格式（JPEG、PNG、GIF、BMP、WebP、AVIF、ICO、CUR、SVG）。
- **Data URI 图片提取**：支持提取内嵌在HTML中的Data URI格式图片。

### 🛠️ 通用功能

- **批量处理能力**：支持一次性处理整个文件夹下的多个MHT文件。
- **按修改时间排序合并**：在合并输出模式下，根据文件的最后修改时间自动排序，保证内容逻辑连贯。
- **单独输出模式**：为每个MHT文件生成独立的输出目录或文件。
- **高速内存模式**：可选预加载所有文件到内存以加速处理（含内存用量警告提示）。
- **处理进度显示**：实时进度条与状态反馈，支持处理中随时取消。
- **配置管理**：支持配置的保存、加载与删除，配置以JSON格式存储在`config/`目录下。
- **自定义日志系统**：基于Logback的自定义Appender，将日志实时输出到GUI界面的文本区域。
- **提取完成自动打开文件夹**：可选在提取完成后自动打开输出目录。

## 🚀 使用指南

### 系统要求

- **操作系统**：Windows / Linux / macOS
- **JDK版本**：Java 21+（重构后升级）
- **内存建议**：至少512MB可用内存以流畅处理大型MHT文件

### 安装与运行



### 基本使用流程

1. 启动GUI界面后，通过顶部「模式选择」切换「文本提取」或「图片提取」工作模式。
2. 设置输入文件夹路径，包含待处理的MHT文件（选择输入目录后自动设置输出目录）。
3. 指定输出路径，用于存放提取后的结果文件。
4. 在对应参数Tab页中配置提取选项（内容限定、模板、章节号等）。
5. 点击「开始提取」按钮启动处理任务。
6. 查看底部日志输出确认执行状态，进度条实时显示处理进度。
7. 提取完成后可自动打开输出目录查看结果。

## 🔧 高级配置说明

### 内容区域限定

通过定义起始与结束标记，可以精确控制仅提取HTML源码中的某一部分内容。此功能同时适用于文本提取和图片提取场景。

| 参数          | 说明                                             |
| ------------- | ------------------------------------------------ |
| `startMarker` | 起始HTML标签或正则表达式，作为内容截取的起点     |
| `endMarker`   | 结束HTML标签或正则表达式，作为内容截取的终点     |
| `useRegex`    | 是否启用正则匹配模式，开启后支持更复杂的定位逻辑 |

### 自定义模板变量

在输出模板中使用以下动态变量，可使每次生成的内容更具个性化：

| 变量名       | 替换值                                          |
| ------------ | ----------------------------------------------- |
| `{filename}` | 当前MHT文件的原始文件名                         |
| `{datetime}` | 文件的最后修改时间（格式：yyyy-MM-dd HH:mm:ss） |
| `{date}`     | 仅日期部分（yyyy-MM-dd）                        |
| `{time}`     | 仅时间部分（HH:mm:ss）                          |
| `\n`         | 插入换行符（在模板输入框中按Enter键插入）       |

> 示例模板：
> `\n========== START ==========\n文件：{filename} ({datetime})\n`

### 配置管理

- 支持将当前所有配置项保存为JSON格式文件，便于后续快速加载复用。
- 提供配置导入功能，一键恢复历史设置。
- 支持删除不再需要的配置。
- 所有配置文件均存储于项目根目录下的 `config/` 子目录中。

## 🔨 构建说明

### 构建环境

- **JDK版本**：21+

```bash
mvn javafx:run
```
