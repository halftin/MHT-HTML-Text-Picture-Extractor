# MHT资源提取器

> 📝🖼️🛠️ 一款用于从 `.mht` 文件中提取纯文本与图片资源的图形化工具，支持内容区域限定、自定义输出模板与批量处理。

---

## 📖 项目简介

MHT资源提取器是一款专注于解析和提取`.mht`（MIME HTML）文件内容的开源工具。它能够将网页归档文件中的纯文本与嵌入式图片等资源高效分离，并以结构化的方式输出。本工具采用本地运行模式，无需联网即可操作，确保了用户数据的安全性与隐私性。无论是开发者需要复用网页设计素材，研究者希望归档网页文本内容，还是普通用户想提取MHT中的图片与文档，该工具都能提供专业、高效的解决方案。

## ⚙️ 主要功能

### 📝 纯文本提取

- **智能编码修复**：自动检测并修复UTF-8、GBK等常见编码导致的乱码问题，确保中文内容准确无误。
- **内容区域限定**：通过设置起始与结束标记，仅提取HTML中指定区间的文本内容，避免无关信息干扰。
- **灵活输出模板**：支持默认及自定义输出模板，可动态插入文件名、时间戳等变量，满足多样化排版需求。

### 🖼️ 图片提取

- **广告过滤机制**：基于关键词列表自动识别并过滤广告类图片（如banner、promo等），提升资源纯净度。
- **智能重命名规则**：支持按数字序列（001.jpg, 002.png...）对提取的图片进行重命名，便于管理和排序。
- **ZIP打包输出**：可选将所有提取的图片打包为ZIP压缩文件，方便传输与存储。

### 🛠️ 通用功能

- **批量处理能力**：支持一次性导入整个文件夹下的多个MHT文件，实现高效批量转换。
- **按修改时间排序合并**：在合并输出模式下，可根据文件的最后修改时间自动排序，保证内容逻辑连贯。
- **单独输出模式**：允许为每个MHT文件生成独立的TXT或图片文件夹，适用于精细化管理场景。

## 🚀 使用指南

### 系统要求

- **操作系统**：Windows / Linux / macOS
- **Java版本**：JRE 11 或更高版本
- **内存建议**：至少512MB可用内存以流畅处理大型MHT文件

### 安装与运行

#### 下载发布包

```bash
# 访问 Releases 页面下载 mht-extractor-v1.0.jar
wget https://gitee.com/your-repo/mht-extractor/releases/download/v1.0/mht-extractor-v1.0.jar
```

#### 运行程序

```bash
java -jar mht-extractor-v1.0.jar
```

### 基本使用流程

1. 启动GUI界面后，选择“纯文本提取”或“图片提取”工作模式。
2. 设置输入文件夹路径，包含待处理的MHT文件。
3. 指定输出路径，用于存放提取后的结果文件。
4. （可选）启用内容区域限定功能，设定起始与结束标记以截取特定内容。
5. （可选）配置自定义输出模板，利用动态变量增强输出格式灵活性。
6. 点击“开始执行”按钮启动处理任务。
7. 查看日志输出确认执行状态，并打开输出目录检查最终成果。



## 🔧 高级配置说明

### 内容区域限定

通过定义起始与结束标记，可以精确控制仅提取HTML源码中的某一部分内容。此功能特别适用于只关注文章正文而忽略页眉页脚等非核心信息的场景。

| 参数          | 说明                                             |
| ------------- | ------------------------------------------------ |
| `startMarker` | 起始HTML标签或正则表达式，作为内容截取的起点     |
| `endMarker`   | 结束HTML标签或正则表达式，作为内容截取的终点     |
| `useRegex`    | 是否启用正则匹配模式，开启后支持更复杂的定位逻辑 |

### 自定义模板变量

在输出模板中使用以下动态变量，可使每次生成的内容更具个性化和上下文关联性：

| 变量名       | 替换值                                          |
| ------------ | ----------------------------------------------- |
| `{filename}` | 当前MHT文件的原始文件名                         |
| `{datetime}` | 文件的最后修改时间（格式：yyyy-MM-dd HH:mm:ss） |
| `{date}`     | 仅日期部分（yyyy-MM-dd）                        |
| `{time}`     | 仅时间部分（HH:mm:ss）                          |
| `\\n`        | 插入换行符                                      |

> 示例模板：  
> `\\n========== START ==========\\n文件：{filename} ({datetime})\\n`

### 配置管理

- 支持将当前所有配置项保存为JSON格式文件，便于后续快速加载复用。
- 提供配置导入功能，一键恢复历史设置，提高多任务切换效率。
- 所有配置文件均存储于项目根目录下的 `config/` 子目录中，易于备份与迁移。

## 🔨 构建说明

### 构建环境

- **JDK版本**：11+
- **构建工具**：Maven 3.6+

### 构建命令

```bash
mvn clean package
```

成功执行上述命令后，可在 `target/` 目录下找到生成的可执行JAR文件，例如 `mht-extractor-*.jar`。
