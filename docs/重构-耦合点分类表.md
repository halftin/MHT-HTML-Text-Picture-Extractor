## 六、#23 模板变量契约（文档化）

`FileWriter.processTemplate`（`output/FileWriter.java:74`）被**预览渲染**（`MC:4449-4450`）与**正式输出**共用，是静态纯函数。契约：

| 变量 | 含义 | 来源 |
|---|---|---|
| `{filename}` | 源 MHT 文件名（不含扩展名） | 调用方传入 |
| `{datetime}` | 日期时间 | `AppConfig` / `I18n("params.datetimeFormat")` |
| `{date}` | 日期 | 同上 |
| `{time}` | 时间 | 同上 |
| `\n` | 换行 | 字面替换 |

**已知边界（登记）**：模板变量拼错会**静默消失**（`FileWriter:77-91`），不报错。预览与正式输出共用同一实现，是 P10"预览与提取同源"约束的一部分——**不得拆分**。
