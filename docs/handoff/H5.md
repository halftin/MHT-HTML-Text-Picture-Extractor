## ⚠️ 行为变更（R5）
1. **归档失败不再删源目录**（修复不可逆数据丢失）：现在记 FAILED（含 failDetail，注明图片保留路径），用户可在日志/详情中看到。此前源目录被删、只剩半截 zip。
2. **全部写入失败不再显示绿色 SUCCESS**：`saved == 0` → FAILED「全部 N 张图片写入失败」。此前 GUI 绿成功但输出目录为空。
3. **预加载模式不可解析文件的图片归属修正**：此前后续文件的图片被写到前一个文件名下、尾部文件越界失败；现在各文件归属正确、不可解析文件记 SKIPPED/FAILED（每文件恰好一条结果）。
4. **预加载模式合并目录名与流式对齐**：首个文件不可解析时回退默认目录名（此前取"第一个解析成功文件"的标题，即错位文件）。
5. **预加载模式全部文件不可解析时**：不再提前返回——每个文件仍逐条记录 SKIPPED/FAILED；合并模式下会先创建空的合并目录（与流式模式行为一致；见「新发现」1）。
6. **预加载模式取消**：结果记录从 preloadAll 移入 processUnified 后，取消时未处理文件无结果记录（此前失败文件在 preload 阶段即时记录、成功文件同样无记录——现在一致）。
