## 转义与占位符约定

- bundle 为 UTF-8 直写（JDK 9+ JEP 226，已实测）；值内 `\n` = 运行时换行，字面反斜杠+n 写作 `\\n`。
- 值首/尾空格用 `\ ` 转义（`Properties.load` 会剥离开头空格）。
- 拼接式文案已改写为具名占位符（如 `"输出文件：" + x + ".txt"` → `preview.outputFilePrefix` + `preview.outputFileTxtSuffix`）；
  `%d`/`%s`/`%n`/`{}`（slf4j）→ `{name}`（会话 14/15 同步改 Java 侧格式串）。
- `param.text.templateVars` 中的 `{filename}` 等是 **FileWriter 模板变量**，不是 i18n 占位符；FXML `%key` 注入不经过 `I18n.get`，无冲突。
- `test.*` 键仅为满足 319 条完整性而建立；需求文档 §3.1 明确「测试/演练代码不外置」，会话 14 **不替换**这些调用点。
- `core.digit.*` / `core.chapter.*` 的 en 值为占位翻译，最终由会话 15 `WesternChapterNamingStrategy` 定夺。
- `core.defaultOutputName` / `core.groupDefault`（§8.3）：zh 值保留既有行为，仅 en 变化。
