## 五、执行时必须知道的 8 条（浓缩自 CLI 指南）

1. **会话权限必须完全权限**，否则子进程全部 `0xC0000142`（状态：本会话已确认可用）
2. **`mvn` 不在 PATH** → `source .claude-work/env.sh`（提供 `mvnx`/`mvncompile`/`mvntest`/`mvntest1`/`run-test-mode`）
3. **GUI 回归不能 `mvn javafx:run -Dtest.mode=true`**（`-D` 被 Maven 吃掉）→ 用 `run-test-mode`
4. **`mvn -q test` 吞 surefire 摘要** → 看摘要时不要加 `-q`
5. **git 身份未配置** → `git -c user.name="Administrator" -c user.email="admin@mht-extractor.local" commit`
6. **不要往 `src/main/resources` 放临时文件** → 会被 Maven 打进 jar（本项目真发生过）
7. **行号会漂移** → 引用任何文档里的行号前先 `grep -n` 复核
8. **外包给 Claude CLI 的结论必须独立复验** → 它可能过度乐观；且验证脚本自身也可能有错
