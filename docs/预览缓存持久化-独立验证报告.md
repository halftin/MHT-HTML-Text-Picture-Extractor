## 四、执行期间由 DSH 发现并修掉的问题

| 问题 | 影响 | 处理 |
|---|---|---|
| `mvn` 不在 PATH（无 `shell` mvn） | **会让全部会话的构建/测试失败** | 建 `.claude-work/env.sh`（导出 NIK25 JAVA_HOME + wrapper mvn），并修正全部提示词 |
| `.gitignore:8` 的 `config/` 未锚定 | 误伤 `src/test/java/com/mhtextractor/config/`，新测试被静默忽略 | 改为 `/config/`、`/logs/`、`/temp/`、`/输出文件/`，已验证 4 条规则仍生效、src/test 不再被忽略 |
| PowerShell 的 `$args` 是自动变量 | 驱动脚本静默失效（0 字节输出） | 改用 Node 驱动（原生 spawn，UTF-8 无损） |
| 提示词中的 `git add -A` 会互相污染暂存区 | 并行会话会覆盖彼此改动 | 改为精确暂存各自文件 |
| PS 5.1 按 GBK 读无 BOM 的 UTF-8 脚本 | 中文脚本解析失败 | 改用 `[scriptblock]::Create` 或加 BOM |

## 七、给后续会话的关键事实

1. **构建必须** `source .claude-work/env.sh`（本机无 PATH mvn）。
2. **`mvn javafx:run -Dtest.mode=true` 不生效**（`-D` 被 Maven 吃掉），必须用 `run-test-mode`（直接 java）。
3. **看 surefire 摘要不要加 `-q`**（`mvnx -Dtest=X test`）。
4. **git 提交必须内联身份**（仓库未配置 user.name/email）。
5. `ImageSource` 已抽象（会话 6）；`ParamScope.effectiveImageParams` 是图片参数的唯一入口（会话 7）；
   `PreviewCacheStore`/`PreviewCacheLifecycle` 是缓存的两层（会话 8/9）；
   `ImageBatchProcessor(config, previewCacheLifecycle)` 是复用的唯一注入点（会话 10）。
6. **阶段 A 冻结的输出语义不得回归**：`saved>0`→SUCCESS、`saved==0`→FAILED、归档失败保留源目录、
   预加载按 `fileIndex` 归属、每文件恰好一条 `FileResult`。
